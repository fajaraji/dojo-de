# Dojo v2: SQL + Data Modeling & Warehouse — Rencana Implementasi

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengganti Dojo lama dengan kursus berbahasa Indonesia yang urut, lengkap, dan ramah pemula. Latihan SQL-nya dijalankan PostgreSQL asli di browser. Rencana ini mencakup Bagian 1 (SQL) dan Bagian 2 (Data Modeling & Warehouse).

**Architecture:** Situs statis di Cloudflare Pages (paket gratis), diterbitkan dari repo GitHub (keputusan 26 Nov, menggantikan Artifact). Halaman memuat materi per bab dari berkas terpisah. Query dijalankan PostgreSQL 18 (PGlite 0.5.16) di Web Worker, yaitu proses terpisah di browser yang bisa dimatikan kalau query macet. Setiap soal punya solusi rujukan. Sebelum terbit, semua solusi dijalankan otomatis oleh pemeriksa materi di Node.

**Tech Stack:** HTML/CSS/JavaScript ES module tanpa framework; PGlite 0.5.16 disajikan dari folder sendiri; `node:test` untuk uji otomatis; Git + GitHub + Cloudflare Pages.

**Spec:** Bagian "Spesifikasi" di bawah (dari pesanmu 26 Nov 2026) dan `docs/riset/2026-11-26-dataprojecthunt.md`.

## Global Constraints

- **Bahasa.** Materi dalam bahasa Indonesia. Setiap istilah teknis, kata bahasa Inggris, dan nama kolom dijelaskan dengan kalimat biasa saat pertama dipakai.
- **Mesin.** PGlite 0.5.16 (PostgreSQL 18.6), disajikan dari `dojo/vendor/pglite-0.5.16/`. Nama `pglite-data.wasm` (bukan `pglite.data`) dipertahankan supaya kode sama untuk server lokal dan Cloudflare.
- **Batas waktu query.** Query pengguna berjalan di Web Worker dengan batas waktu 8 detik. Kalau lewat, worker dimatikan dan mesin dinyalakan ulang.
- **Isolasi latihan.** Setiap latihan dijalankan dalam transaksi yang dibatalkan (`BEGIN … ROLLBACK`), kecuali latihan di bab transaksi. Data latihan tidak boleh berubah dari satu soal ke soal lain.
- **Pustaka dari luar.** Tidak ada, kecuali font dari Google Fonts. Versi pustaka selalu pasti dan minimal berumur 2 minggu.
- **Aturan keamanan halaman.** Ditulis sendiri di berkas `dojo/_headers` milik Cloudflare Pages: skrip hanya dari situs sendiri, WebAssembly diizinkan (`'wasm-unsafe-eval'`), `eval` tidak diizinkan.
- **Data latihan.** Data fiktif "TokoKita" (toko online), dibuat dengan seed tetap 20261126. Tidak memuat data dari tempat kerja mana pun.
- **Progres.** Disimpan di `localStorage` dengan awalan `dojo2:`. Halaman tetap berfungsi kalau penyimpanan diblokir.
- **Hosting.** Rilis diterbitkan ke Cloudflare Pages dari repo GitHub. Akun Cloudflare dan GitHub dibuat dan dipegang olehmu; Claude tidak membuat akun atau login.
- **Git.** Sampai T05 selesai, langkah "commit" diganti dengan memperbarui status tiket di dokumen ini. Setelah repo dibuat di T05, commit dan push hanya dilakukan dengan persetujuanmu.
- **Gaya tulis.** Gaya tulis materi mengikuti `dojo/STYLE.md` (dibuat di T04).

## Review Focus

1. **Pengguna mengetik T-SQL** (TOP, ISNULL, GETDATE, `[kolom]`, `+` untuk menggabung teks): pesan error harus menjelaskan padanan PostgreSQL-nya. Diuji di T03 (`hints.test.mjs`).
2. **Query tanpa ujung** (rekursi tanpa batas, CROSS JOIN raksasa): berhenti setelah 8 detik, mesin menyala ulang, dan halaman tidak beku. Diuji di T02 (`#uji` cek 3).
3. **Pengguna menjalankan DELETE/DROP/UPDATE di soal**: data untuk soal berikutnya tetap utuh. Diuji di T02 (`#uji` cek 4).
4. **Jawaban benar dalam bentuk berbeda** (nama kolom lain, urutan baris lain padahal urutan tidak diminta, format angka `1.50` lawan `1.5`): tetap diterima. Kalau jumlah kolomnya salah, kesalahannya dijelaskan. Diuji di T03 (`checker.test.mjs`).
5. **Mesin gagal dimuat** (WebAssembly diblokir, jaringan lambat): status yang jelas tampil, dan materi tetap bisa dibaca. Diuji di T02 (`#uji` cek 1 dan mode `/strict/` di server lokal).

### T00: Uji coba mesin PostgreSQL di browser (selesai di lokal)

Temuan:
- **Versi.** PGlite 0.5.16 menjalankan PostgreSQL 18.6.
- **Waktu nyala.** Mesin menyala 3–4 detik di browser. Berkas mesin yang diunduh saat kunjungan pertama sekitar 15 MB.
- **Izin yang dibutuhkan.** Mesin butuh izin WebAssembly (`'wasm-unsafe-eval'`), tapi tidak butuh `eval`. Tanpa izin WebAssembly, mesin gagal (terbukti di mode `/strict/`).
- **Lokasi berkas JS.** Di dalam *module worker*, berkas JS yang di-import diperiksa dengan aturan `worker-src`. Karena itu, JS PGlite disajikan dari folder sendiri, bukan dari CDN.
- **Query tanpa ujung.** `statement_timeout` tidak menghentikannya; di Node, query macet lebih dari 3 menit. Solusinya: Worker dimatikan dengan `terminate()` lalu mesin dinyalakan ulang (sekitar 3 detik). Cara ini terbukti di browser.
- **Nama opsi.** Opsi PGlite versi ini adalah `pgliteWasmModule`, `initdbWasmModule`, dan `fsBundle`.
- **Bentuk hasil.**
  - Kolom tanggal dikembalikan sebagai objek `Date`, dan kolom numeric sebagai teks.
  - Error membawa `code` dan `position`. Contohnya, `SELECT TOP 5` memberi kode `42601`, dan `ISNULL(...)` memberi kode `42883`.

- **Pemakaian RAM** (diukur di Node, belum di browser): puncak sekitar 620 MB saat membuat database baru, lalu sekitar 350 MB. Memuat database yang sudah disiapkan (`loadDataDir`) menurunkan puncak menjadi sekitar 500 MB dan waktu nyala menjadi 1,5 detik. Pilihan cara muat diputuskan di T01/T02.
- [x] **Uji di Artifact tidak diperlukan lagi:** hosting pindah ke Cloudflare Pages (keputusan 26 Nov). Halaman uji https://claude.ai/artifact/MHui1x2irmMtkaDduoP4R8 tidak dipakai lagi.

### S01: Data, tabel, dan SELECT pertama
- **Perintah baru:** `SELECT`, `FROM`, `*`, `AS`, `LIMIT`, `OFFSET`, `ORDER BY`, `ASC`, `DESC`, komentar `--`.
- **Istilah:** data, database, tabel, baris, kolom, skema, query, SQL, dialek, PostgreSQL, SQL Server, hasil query.
- **Tabel:** `app.products`, `app.customers`, `app.cities`.
- **Di SQL Server:** `TOP n` lawan `LIMIT n`; `OFFSET … FETCH`; `[nama]` lawan `"nama"`.

### S02: Menyaring baris: WHERE dan NULL
- **Perintah baru:** `WHERE`, `=`, `<>`, `!=`, `<`, `>`, `<=`, `>=`, `AND`, `OR`, `NOT`, kurung, `IN (daftar)`, `NOT IN (daftar)`, `BETWEEN`, `LIKE`, `ILIKE`, `%`, `_`, `IS NULL`, `IS NOT NULL`.
- **Istilah:** kondisi, NULL, logika tiga nilai (benar, salah, tidak diketahui).
- **Tabel:** `app.orders`, `app.products`, `app.customers`.
- **Di SQL Server:** `LIKE` biasanya tidak membedakan huruf besar/kecil (tergantung *collation*), sedangkan PostgreSQL membedakan, sehingga perlu `ILIKE`.

### S03: Kolom hitungan, CASE, dan nilai kosong
- **Perintah baru:** operator `+ - * / %`, `ROUND`, `CAST`, `::`, `CASE WHEN … THEN … ELSE … END`, `COALESCE`, `NULLIF`, `DISTINCT`.
- **Istilah:** ekspresi, tipe data (integer, numeric, text, date, boolean), konversi tipe, pembagian bilangan bulat.
- **Tabel:** `app.order_items`, `app.products`, `app.orders`.
- **Di SQL Server:** `ISNULL` lawan `COALESCE`, `IIF` lawan `CASE`, `CAST`/`CONVERT`.

### S04: Teks, tanggal, dan membersihkan data mentah
- **Perintah baru:** `UPPER`, `LOWER`, `TRIM`, `LENGTH`, `SUBSTRING`, `REPLACE`, `POSITION`, `SPLIT_PART`, `||`, `CONCAT`, `CURRENT_DATE`, `NOW`, `DATE_TRUNC`, `EXTRACT`, `INTERVAL`, `AGE`, `TO_CHAR`, `TO_DATE`.
- **Istilah:** timestamp, format tanggal ISO, zona waktu (singkat), data mentah.
- **Tabel:** `raw.supplier_price_upload`, `app.orders`, `app.customers`.
- **Di SQL Server:** `LEN`, `CHARINDEX`, `+`, `GETDATE`, `DATEADD`, `DATEDIFF`, `DATEFROMPARTS`, `FORMAT`, `TRY_CONVERT(date, x, 103)`.

### S05: Meringkas data: agregasi dan GROUP BY
- **Perintah baru:** `COUNT(*)`, `COUNT(kolom)`, `COUNT(DISTINCT)`, `SUM`, `AVG`, `MIN`, `MAX`, `GROUP BY`, `HAVING`, `FILTER (WHERE …)`.
- **Istilah:** agregasi, grain (satu baris hasil mewakili apa).
- **Tabel:** `app.orders`, `app.order_items`, `app.payments`.
- **Di SQL Server:** tidak ada `FILTER`, jadi diganti `SUM(CASE …)`; ada juga `COUNT_BIG`.

### S06: Menggabung tabel: JOIN
- **Perintah baru:** `JOIN`/`INNER JOIN`, `ON`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`, `CROSS JOIN`, `USING`, alias tabel.
- **Istilah:** primary key, foreign key, relasi satu-ke-banyak, baris berlipat (*fan-out*), *anti-join*, *self join*.
- **Tabel:** `app.orders`, `app.order_items`, `app.payments` (pembayaran terpisah menjadi jebakan baris berlipat), `app.customers`, `app.cities`, `app.staff`.
- **Soal wawancara:** total nilai barang dan total pembayaran per pesanan dalam satu query, tanpa angka berlipat.

### M01: Dari aplikasi ke gudang data (prasyarat: S06)
- **Perintah baru:** tidak ada.
- **Istilah:** OLTP, OLAP, normalisasi (1NF, 2NF, 3NF), anomali update, gudang data (*data warehouse*), data mart, lapisan raw/staging/core/mart, *medallion*, ETL, ELT, diagram ER.

- **Istilah:** proses bisnis, grain, dimensi, fakta, measure *additive*/*semi-additive*/*non-additive*, star schema, snowflake schema, jenis tabel fakta (*transaction*, *periodic snapshot*, *accumulating snapshot*, *factless*), *conformed dimension*, *bus matrix*.

### S07: Subquery, EXISTS, dan operasi himpunan
- **Perintah baru:** subquery skalar, `IN (subquery)`, `EXISTS`, `NOT EXISTS`, subquery berkorelasi, `ANY`/`ALL`, `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`.

### S08: CTE dan query panjang

### S09: Window function 1
